One engine, three banks.

All three quizzes share the same multiplayer hosting machinery — only the questions, accents, and audience change.

Multiplayer by default

Host opens a room on a meeting-room screen; the team joins from any phone or laptop via QR code or 4-letter room code. Live leaderboard, no app install, no account needed.

Hand-authored content

Every vignette is written by a clinician against published guidelines. No LLM-generated questions, no scraped MCQ banks. References are clickable and specialty-specific.

Self-contained files

Each quiz is one HTML file with all questions embedded. No backend. No CDN dependency beyond Firebase Realtime Database for multiplayer state and Google Fonts for type.

Namespaced rooms

Each discipline writes to its own Firebase path — rooms/medical/…, rooms/nursing/…, rooms/pharmacy/… — so a medical session and a pharmacy session can run simultaneously without collision.

Deterministic daily mode

Solo learners get one question per day of the year. The same date returns the same question on every device — useful for "question of the day" board displays.

Privacy by design

No analytics. No tracking pixels. No localStorage of personal data. Player names are random 4-letter codes by default; the host shows with a ★ on the leaderboard.

For team administrators

This is the front door — a launcher for all three banks. Each quiz itself runs on GitHub Pages because most NHS SharePoint tenants block JavaScript in uploaded HTML files. This hub can live anywhere: a SharePoint document library, a Modern SharePoint Page (via the Embed or Quick Links web part), or directly on GitHub Pages alongside the quizzes.

Edit the HUB_CONFIG block at the top of the source file to set quiz URLs and the displayed team name. Use relative paths if all four HTML files share a folder; absolute URLs otherwise. See DEPLOY.txt in the repo for the detailed GitHub Pages route.

  1. Open index.html in a text editor and update HUB_CONFIG.
  2. Optionally change ownerName to your team or department.
  3. Upload index.html plus the three quiz HTML files to GitHub Pages.
  4. Share the hub URL — pin it to Teams, SharePoint, or a teaching handout.
